# ZCode на русском

Русский интерфейс для **ZCode Desktop на macOS**. Ставится одной командой, откатывается
тоже одной. Плагины, MCP и скиллы продолжают работать — потому что меняются только тексты,
а не код приложения.

Русская локализация **основана на работе проекта
[zcode-ru](https://github.com/warment/zcode-ru)** — им спасибо: оттуда взят и сам подход,
и основа словаря. Подробнее — в разделе [«Благодарности»](#благодарности).

**Требования:** macOS 13 или новее, установленный ZCode **3.17.2** (сборка 9661),
~400 МБ свободного места на время установки. Права администратора (`sudo`) не нужны.

Для другой версии ZCode — [раздел про сборку](#другая-версия-zcode).

---

## Установка

**1. Закройте ZCode** — Cmd+Q. Установщик не станет трогать работающее приложение.

**2. Откройте «Терминал» и вставьте одну строку:**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DmitryKrylovv/zcode-ru-mac/main/install.sh)
```

**3. Откройте ZCode → Настройки → Язык → «Русский».**
На русской системе язык подхватится сам.

Что при этом происходит:

- установщик проверяет, что у вас именно 3.17.2 — на другой версии остановится и ничего не тронет;
- скачивает русификатор (~350 МБ) и сверяет контрольную сумму, чтобы не поймать битый файл;
- сохраняет оригинал в `~/.zcode-ru-backup` — это ваша страховка на случай чего;
- подменяет **один файл**, `Contents/Resources/app.asar`, и переподписывает приложение локально;
- запускает ZCode. Если он не открылся за 10 секунд — возвращает оригинал и запускает снова.

## Откат

Вернуть всё как было — одна команда:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DmitryKrylovv/zcode-ru-mac/main/restore.sh)
```

Оригинальный файл возвращается байт в байт из резервной копии.

## Что станет русским

Практически всё, что видно в приложении:

- чат, поле ввода, панели, кнопки, подсказки, ошибки, пустые состояния;
- настройки целиком — модели, провайдеры, плагины, MCP, хуки, скиллы, субагенты, автоматизации;
- проекты, задачи, сессии, архив, синхронизация на удалённые устройства, SSH / WSL / Docker;
- встроенный браузер и разрешения сайтов, публикация беседы, статистика использования;
- верхнее меню macOS, иконка в трее, диалог «О программе»;
- сам переключатель языка — в списке появляется «Русский».

Всего переведено **7 265 строк** — это весь текст, который есть внутри приложения.
Заодно исправлены 82 строки, где английский оригинал изменился между версиями 3.14.3 и
3.17.2: например «workspace» стал «project», а «safety checks» — «подтверждением публикации».
Старые переводы в этих местах врали, потому что опирались на прежний текст.

## Что останется на английском

Не потому, что забыли, а потому что этих строк физически нет в приложении — они приходят
с сервера Z.ai в момент показа:

- описание обновлений (release notes) и приветственные шаблоны;
- раздел Indexing;
- часть ошибок серверной стороны — например, текст ошибки удалённого подключения
  приходит с удалённого компьютера.

Плюс то, что не переводят: `MCP`, `SSE`, `GLM`, `PID`, `Computer Use`, имена моделей,
адреса и пути к файлам.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `ZCode запущен. Закройте его (Cmd+Q)` | Правда закройте — установщик принципиально не трогает работающее приложение |
| `этот выпуск собран под ZCode 3.17.2, а у вас …` | Значит у вас другая версия: [соберите под свою](#другая-версия-zcode) |
| `контрольная сумма не совпала` | Архив скачался не полностью. Удалите его и повторите — установщик ничего не изменил |
| ZCode не открывается после установки | Установщик сам откатится. Если откат не сработал — запустите `restore.sh` |
| Язык остался английским | Настройки → Язык → «Русский» |
| macOS пишет, что разработчик не проверен | Так и должно быть после локальной переподписи. Откройте через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» |
| Пропали разрешения (запись экрана, универсальный доступ) | Выдайте их заново — обычное следствие переподписи, это одноразово |
| После обновления ZCode всё снова на английском | Ожидаемо: обновление возвращает оригинальный файл. Запустите установщик снова |

## Три вещи, о которых стоит знать

**1. Разрешения.** Чтобы приложение запускалось после подмены файла, установщик переподписывает
его локально (подпись Z.ai при этом заменяется). Из-за этого macOS может один раз заново
спросить «Запись экрана» и «Универсальный доступ». Это не поломка — просто выдайте разрешения
ещё раз.

**2. Обновления.** Когда ZCode обновится, он вернётся к английскому. Это нормально: после
обновления запустите установщик снова. Он проверяет версию и сам скажет, если для новой
версии нужен новый выпуск русификатора.

**3. Версия.** Русификатор собран строго под 3.17.2. На другой версии установщик ничего не
сделает — так и задумано, иначе получится несогласованный интерфейс.

## Почему у других русификаторов ломаются плагины

Готовые сборки обычно делают так: берут `app.asar`, собранный под какую-то одну версию
(например 3.14.3), и подменяют им файл целиком. Приложение превращается в «версию 3.14.3
в оболочке 3.17.2» — и плагины, MCP и скиллы перестают совпадать по версии.

Здесь наоборот: берётся **ваш** `app.asar`, и меняются только файлы с текстами — 17 файлов
из 31 826. Остальное переносится байт в байт, включая нативные модули и код, который
загружает плагины. Версия кода остаётся ровно та, что у вас установлена, поэтому в логе
после установки видно `plugin-management.listPlugins OK`.

## Проверить, не устанавливая

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DmitryKrylovv/zcode-ru-mac/main/install.sh) --check
```

Скачает архив и сверит контрольную сумму, но приложение не тронет.

## Другая версия ZCode

Сборка занимает минуту и всегда даёт файл, точно совпадающий с вашей установкой:

```bash
git clone https://github.com/DmitryKrylovv/zcode-ru-mac && cd zcode-ru-mac
npm run build      # читает /Applications/ZCode.app и пишет build/app-ru.asar
npm run validate   # сверяет результат с оригиналом по каждому файлу
./install.sh
```

Нужен только Node 20+ и никаких зависимостей. `npm install` понадобится лишь для
`npm run extract` — сверки словаря с текстами новой версии приложения.

Порядок обновления русификатора под новую версию ZCode:

```bash
npm run extract    # вытащить тексты из новой версии (нужен npm install)
npm run check      # покажет, сколько новых строк осталось без перевода
#   перевести новые строки в dict/ru/*.json — check подскажет, где разошлись плейсхолдеры
npm run build && npm run validate
```

Затем поправить в `install.sh` значения `EXPECT_VER`, `EXPECT_SHA` и (при желании) `TAG`,
и выложить новый релиз.

## Для параноиков

- в репозитории **нет** готового архива — только словарь и скрипты; архив собирается из вашей
  установки, поэтому всегда ей соответствует;
- сборка детерминирована: sha256 архива для 3.17.2 —
  `c1dd8ac567fbd06ed0c80ff6c30577542a2d46cd7a7c99c6cae118efc8ceb81b`, установщик сверяет его
  перед установкой;
- весь код — несколько скриптов на bash и Node, они лежат здесь же и читаются за пять минут;
- исполняемые файлы Electron не меняются: правки только в словарях внутри `app.asar`;
- технические подробности (fuse-флаги, формат asar, что именно патчится, как проверялось) —
  в [NOTES.md](NOTES.md).

## Благодарности

**Спасибо проекту [zcode-ru](https://github.com/warment/zcode-ru) (MIT).** Он первым сделал
русскую локализацию ZCode, и эта работа — продолжение его работы, а не самостоятельная
поделка с нуля.

Что взято оттуда:

- **основа словаря** — 6 115 переводов в `dict/ru/01.json` … `19.json`. Для 3.17.2 из них
  подошли 5 881; остальные 234 относились к строкам, которых в новой версии уже нет;
- **сам подход**: правка словарей внутри `app.asar` — реестр локалей `IntlProvider`,
  пункт «Русский» в селекторе языка, схемы локалей в слоях бандла;
- **скрипт извлечения текстов** `scripts/extract.mjs` и глоссарий терминологии, по которому
  этот словарь переведён (тон «вы», инфинитивы на кнопках, число-нейтральные формы для
  множественного числа);
- понимание, что переключатель языка принимается, но не применяется, если пропустить хотя бы
  один слой со схемой локали, — самый коварный симптом при такой правке.

Что сделано здесь:

- **изменён способ установки.** Готовые релизы обычно подменяют `app.asar` целиком сборкой
  под одну конкретную версию — и приложение начинает работать кодом чужой версии, из-за чего
  ломаются плагины. Здесь патчится **ваш** `app.asar`: меняются 17 файлов из 31 826,
  остальное переносится байт в байт, версия кода остаётся вашей;
- **допереведено 1 384 строки**, появившиеся в 3.17.2 (удалённые устройства, проекты,
  архив, синхронизация, SSH / WSL / Docker, воркфлоу и их «пропуски»);
- **исправлены 82 строки**, где английский оригинал изменился между 3.14.3 и 3.17.2, —
  в этих местах старый перевод был неверен;
- установщик, откат, проверка контрольной суммы и валидатор, сверяющий сборку с оригиналом
  по каждому файлу.
