# ZCode на русском

Русский интерфейс для **ZCode Desktop на macOS**. Ставится одной командой, откатывается тоже
одной командой. Плагины, MCP и скиллы продолжают работать.

Сейчас поддерживается **ZCode 3.17.2** (сборка 9661). Для другой версии — раздел
[«Другая версия ZCode»](#другая-версия-zcode).

---

## Установка

**1. Закройте ZCode** — Cmd+Q. Установщик не станет трогать работающее приложение.

**2. Откройте «Терминал» и вставьте одну строку:**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DmitryKrylovv/zcode-ru-mac/main/install.sh)
```

**3. Откройте ZCode → Настройки → Язык → «Русский».**
Если система русская, язык подхватится сам.

Что при этом происходит:

- установщик проверяет, что у вас именно 3.17.2 — на другой версии он остановится и ничего не тронет;
- скачивает русификатор (~350 МБ) и сверяет контрольную сумму, чтобы не поймать битый файл;
- сохраняет оригинал в `~/.zcode-ru-backup` — это ваша страховка;
- подменяет **один файл**, `Contents/Resources/app.asar`, и переподписывает приложение локально;
- запускает ZCode. Если он не открылся — возвращает оригинал и запускает снова.

## Откат

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DmitryKrylovv/zcode-ru-mac/main/restore.sh)
```

Или, если репозиторий уже склонирован: `./restore.sh`.

## Что станет русским

Практически всё, что вы видите в приложении:

- чат, композер, панели, кнопки, подсказки, ошибки и пустые состояния;
- настройки целиком — модели, провайдеры, плагины, MCP, хуки, скиллы, субагенты, автоматизации;
- проекты, задачи, сессии, архив, синхронизация на удалённые устройства, SSH/WSL/Docker;
- встроенный браузер и разрешения сайтов, публикация беседы, статистика использования;
- верхнее меню macOS, иконка в трее, диалог «О программе»;
- переключатель языка — в списке появляется «Русский».

Всего переведено **7 265 строк** — это весь текст, который есть внутри приложения. Заодно
поправлено 82 строки, где английский оригинал изменился между версиями 3.14.3 и 3.17.2
(например, «workspace» стал «project», а «safety checks» — «подтверждением публикации»);
старые переводы в этих местах врали.

## Что останется на английском

Не потому, что забыли, а потому что этих строк физически нет в приложении — они приходят
с сервера Z.ai в момент показа:

- описание обновлений (release notes) и приветственные шаблоны;
- раздел Indexing;
- часть ошибок от серверной стороны — например, текст ошибки удалённого подключения
  приходит с удалённого компьютера.

Плюс технические названия, которые не переводят: `MCP`, `SSE`, `GLM`, `PID`, `Computer Use`,
имена моделей, адреса и пути.

## Три вещи, о которых стоит знать

**1. Разрешения.** Чтобы приложение запускалось после подмены файла, установщик переподписывает
его локально. Из-за этого macOS может один раз заново спросить «Запись экрана» и
«Универсальный доступ». Это не поломка — просто выдайте разрешения ещё раз.

**2. Обновления.** Когда ZCode обновится, он вернётся к английскому. Это нормально: после
обновления запустите установщик снова (он проверяет версию и сам скажет, если нужен новый
выпуск русификатора).

**3. Версия.** Русификатор собран строго под 3.17.2. На другой версии установщик ничего не
сделает — так и задумано, иначе можно получить несогласованный интерфейс.

## Почему у других русификаторов ломаются плагины

Готовые сборки обычно делают так: берут `app.asar`, собранный под какую-то одну версию
(например 3.14.3), и подменяют им файл целиком. Приложение становится «версией 3.14.3
в оболочке 3.17.2» — и плагины, MCP и скиллы перестают совпадать по версии.

Здесь наоборот: берётся **ваш** `app.asar` и меняются только файлы с текстами — 17 файлов
из 31 826. Остальное переносится байт в байт, включая нативные модули и код, который
загружает плагины. Версия кода остаётся ровно та, что у вас установлена.

Поэтому после установки в логе видно `plugin-management.listPlugins OK` — плагины
работают как обычно.

## Проверить, не устанавливая

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/DmitryKrylovv/zcode-ru-mac/main/install.sh) --check
```

Скачает архив и сверит контрольную сумму, но ничего не тронет.

## Другая версия ZCode

Сборка занимает минуту и всегда даёт файл, точно совпадающий с вашей установкой:

```bash
git clone https://github.com/DmitryKrylovv/zcode-ru-mac && cd zcode-ru-mac
npm run build      # читает /Applications/ZCode.app и пишет build/app-ru.asar
npm run validate   # сверяет результат с оригиналом по каждому файлу
./install.sh
```

Для сборки нужен только Node 20+, никаких зависимостей (`npm install` требуется лишь
для `npm run extract` — сверки словаря с новой версией приложения).

Порядок обновления русификатора под новую версию ZCode:

```bash
npm run extract    # вытащить тексты из новой версии (нужен npm install)
npm run check      # покажет, сколько новых строк осталось без перевода
#   перевести новые строки в dict/ru/*.json — check подскажет, где плейсхолдеры разошлись
npm run build && npm run validate
```

Затем поправить `EXPECT_VER` (и `EXPECT_SHA`, если поменялся архив) в `install.sh`.

## Для роботов и параноиков

- архив в репозитории не хранится — только словарь и скрипты, так что «сборка» всегда
  соответствует вашей версии приложения;
- сборка детерминирована: sha256 `app-ru.asar` для 3.17.2 —
  `c1dd8ac567fbd06ed0c80ff6c30577542a2d46cd7a7c99c6cae118efc8ceb81b`;
- установщик сверяет эту сумму перед установкой;
- весь код — несколько скриптов на Node и bash, их можно прочитать здесь же;
- технические подробности (fuse-флаги, формат asar, что именно патчится) — в [NOTES.md](NOTES.md).

## Если репозиторий приватный

Тогда команде `curl` нужен доступ. Проще всего один раз выполнить `gh auth login` —
установщик сам воспользуется `gh`. Либо передать токен явно:

```bash
GITHUB_TOKEN=$(gh auth token) bash <(curl -fsSL https://raw.githubusercontent.com/DmitryKrylovv/zcode-ru-mac/main/install.sh)
```
