# ZCode RU 3.17.2

Русская локализация ZCode Desktop **3.17.2**, собранная под установленную версию, а не под чужую.

## Почему это не ломает плагины

Готовый `app-ru.asar` из проекта `warment/zcode-ru` собран под ZCode **3.14.3**. Установка
подменяет бандл целиком — приложение 3.17.2 начинает работать кодом 3.14.3, и плагины,
MCP и скиллы ломаются из-за рассинхрона версий.

Здесь наоборот: берётся **ваш** `app.asar` 3.17.2 и патчатся только файлы со словарями
(**17 файлов**). Остальные 31 809 файлов переносятся байт-в-байт — включая нативные
модули (`node-pty`, `sharp`, `ssh2`) и код plugin-host. Версия кода остаётся 3.17.2,
поэтому плагины работают как обычно.

## Быстрый старт

Репозиторий **не хранит** готовый `app-ru.asar` (350 МБ) — он собирается из вашей установки
за минуту, поэтому пакет всегда точно совпадает с версией на диске.

```bash
git clone <адрес-репозитория> && cd zcode-ru
npm run build        # читает /Applications/ZCode.app и пишет build/app-ru.asar
./install.sh         # ZCode перед этим закрыть (Cmd+Q)
```

`install.sh` сам найдёт архив в `build/`. Требуется Node 20+; `npm install` нужен только
для `npm run extract` (сверка корпуса), для сборки и установки зависимостей не требуется.

## Установка

Закройте ZCode (Cmd+Q) — установщик не трогает работающее приложение. Затем:

```bash
cd "/Users/dvykrylov/Downloads/untitled folder 2/zcode-ru-3.17.2"
./install.sh
```

Скрипт проверит, что установлена именно 3.17.2, сделает бэкап в `~/.zcode-ru-backup`,
подменит `app.asar`, сбросит quarantine, переподпишет приложение ad-hoc и запустит ZCode.
Если приложение не стартует — сам вернёт оригинал и перезапустит.

Язык: **Настройки → Язык → «Русский»** (при русской системной локали выбирается сам).

## Важно знать

1. **Подпись.** После патча подпись Developer ID заменяется на ad-hoc
   (`codesign --force --deep --sign -`). Локально всё работает, но macOS может заново
   запросить «Запись экрана» и «Универсальный доступ». Это не поломка.
2. **Проверка целостности asar.** В 3.17.2 fuse `EnableEmbeddedAsarIntegrityValidation`
   выключен, поэтому подмена `app.asar` допустима (в Info.plist при этом лежит устаревший
   хеш — он не используется). Если вендор включит fuse, пропатченный архив не загрузится:
   `install.sh` это увидит и откатит.
3. **Обновления ZCode затирают русификацию** и возвращают оригинальную подпись.
   После обновления нужна пересборка.

## После обновления ZCode: пересборка

```bash
cd zcode-ru-3.17.2
npm install                                    # нужен только для extract.mjs
node scripts/extract.mjs /Applications/ZCode.app/Contents/Resources/app.asar
node scripts/check-dict.mjs                    # покажет, сколько новых ключей без перевода
#   перевести новые ключи в dict/ru/*.json (ошибки плейсхолдеров покажет тот же check)
node scripts/patch-asar.mjs /Applications/ZCode.app/Contents/Resources/app.asar build/app-ru.asar
node scripts/validate.mjs /Applications/ZCode.app/Contents/Resources/app.asar build/app-ru.asar
```

Затем поправить `EXPECT_VER` в `install.sh` и переустановить.
`patch-asar.mjs` и `check-dict.mjs` работают без зависимостей (только Node).

## Технические детали

- asar **не распаковывается**: патчер читает заголовок, подменяет содержимое 17 файлов и
  пересчитывает смещения. Распакованные (нативные) файлы остаются на диске как были.
- сборка детерминирована, sha256 пакета:
  `c1dd8ac567fbd06ed0c80ff6c30577542a2d46cd7a7c99c6cae118efc8ceb81b`
- проверено на живой копии приложения: структура 31 826 файлов и 5 unpacked как в
  оригинале, приложение стартует, `plugin-management` RPC отвечает OK, интерфейс на русском.

## Ограничения

- Пакет собран строго под **3.17.2** (build 9661). Для другой версии — пересборка.
- После установки обновление «изнутри» приложения вернёт оригинал: русификация не
  переживает автообновление.
- Не официальный продукт Z.ai.
